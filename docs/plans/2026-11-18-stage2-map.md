# 2단계: 지도 기본 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 지도 탭에 후쿠오카 지도, 일차 탭, 일차별 색상의 번호 마커와 연결선, 숙소·후보 마커를 표시한다(아직 장소 추가 기능 없음 → 예시 장소로 확인).

**Architecture:** Leaflet 1.9.4를 `js/vendor/`에 내장(오프라인에서도 앱 코드는 열림). 표시할 장소를 고르는 순수 로직은 `js/map/model.js`(테스트 대상), 그리는 부분은 `js/tabs/map.js`. 타일은 OpenStreetMap 표준(무료, 키 없음, 온라인 필요). ※ 계획 당시 CARTO Voyager였으나 API 키 요구로 변경, 색은 CSS로 차분하게 조정.

**Spec:** `docs/design.md` 5.1절 지도 화면, 5.4절

## Global Constraints
- 일차 탭: `전체` `12/31(목)` `1/1(금)` `1/2(토)` `1/3(일)` `후보` — 가로 스크롤 칩.
- 일차 색: d1 `#2f6fde`(파랑), d2 `#e8590c`(주황), d3 `#2b9348`(초록), d4 `#9c36b5`(보라). 후보 `#868e96`(회색). 숙소 `#191f28`.
- 순서 기준은 `order`(시간 아님, 설계 5.4).
- 지도 초기 중심: 하카타~텐진 `[33.5902, 130.4017]`, 줌 13. 장소가 있으면 보이는 장소에 맞춰 화면 조정.
- 실제 장소가 0개일 때만 예시 장소를 흐리게 보여주고 상단에 "예시 장소입니다. 3단계에서 직접 추가할 수 있어요." 안내. 예시는 저장하지 않는다.
- 타일 출처 표기 필수: `© OpenStreetMap contributors`.

## Place 데이터 형태 (3단계에서 그대로 사용)
```
{ id, name, lat, lng,
  kind: 'plan' | 'candidate' | 'stay',
  dayId: 'd1'..'d4' | null,     // plan만
  order: number,                // plan: 일차 안 순서
  stayDayIds: string[],         // stay: 묵는 날(박) — 비면 전 일차 표시
  category, time, memo, hours, newYearOpen }   // 3단계 카드용, 지금은 name·time만 사용
```

## Review Focus
1. 좌표가 없거나 숫자가 아닌 장소 → 지도에서 건너뛰고 앱은 멈추지 않는다.
2. 같은 일차에 장소 1개 → 마커만, 선 없음. 0개 → 기본 중심으로.
3. 다른 탭에 갔다가 돌아옴 → 지도를 새로 만들 때 이전 지도 정리(메모리·이벤트 누수 없음), 크기 깨짐 없음.
4. 인터넷 끊김 → 타일은 비어도 마커·선·탭은 보인다.
5. 숙소: `stayDayIds`가 빈 배열이면 모든 일차에, 아니면 해당 일차에만.

### Task 1: 지도 모델 (`js/map/model.js`)
**Produces:**
- `DAY_COLORS: Record<'d1'|'d2'|'d3'|'d4', string>`, `CANDIDATE_COLOR`, `STAY_COLOR`
- `MAP_FILTERS = ['all','d1','d2','d3','d4','candidates']`
- `hasCoords(p): boolean`
- `routeForDay(places, dayId): Place[]` — kind 'plan', 해당 dayId, 좌표 있음, `order` 오름차순
- `visibleLayers(places, filter): { routes: {dayId, color, places}[], candidates: Place[], stays: Place[] }`
  - `all`: 4일차 경로 전부 + 후보 + 숙소 전부
  - `d1..d4`: 그 일차 경로 + 후보(흐리게 표시는 뷰 담당) + 그 날 숙소
  - `candidates`: 후보만 + 숙소 전부
- `SAMPLE_PLACES: Place[]` (예시, 실제 장소와 무관한 대표 명소 10곳 내외)

테스트(`tests/map-model.test.mjs`) 먼저: 순서 정렬, 좌표 없는 장소 제외, 필터별 구성, 숙소 일차 규칙, 알 수 없는 필터 → `all`.

### Task 2: 지도 화면
- Leaflet 1.9.4 `leaflet.js`·`leaflet.css`를 cdnjs에서 받아 `js/vendor/`에 둔다. `index.html`에서 css 링크, `map.js`에서 전역 `L` 사용(클래식 스크립트로 로드).
- `js/tabs/map.js` `mount(el, store)`:
  - 상단 일차 칩(선택값 `ui.mapFilter`에 저장, 기본 `all`), 지도는 남은 화면 전체.
  - 경로: 번호 원형 마커(divIcon, 일차 색) + 같은 색 선. 후보: 회색 작은 원. 숙소: 진한 색 "숙" 마커.
  - 마커 누르면 이름(+시간) 말풍선.
  - 이전 지도 인스턴스는 `map.remove()`로 정리.
- `store.js` `defaultState().ui.mapFilter = 'all'` (테스트 먼저).
- `sw.js` APP_FILES에 새 파일, `CACHE_VERSION` 올림.
- 확인: 390×844 스크린샷(전체 / 1일차 / 후보), 탭 왕복 후 지도 정상, 서버 끈 상태에서 마커 보임, 콘솔 에러 0.
